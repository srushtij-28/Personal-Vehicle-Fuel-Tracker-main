# Personal Vehicle Fuel Tracker

A simple Python command-line application to manage vehicle fuel purchases,
monitor fuel expenses, calculate mileage, and track fuel consumption.

## Features

- Add vehicle details
- View registered vehicles
- Search vehicles by name or registration
- Record fuel purchases
- Track fuel quantity and price
- Calculate estimated mileage
- View fuel purchase history
- Update fuel records
- Delete fuel records
- Calculate total fuel expenses
- Display fuel statistics
- Store data in JSON files

## Technologies Used

- Python
- JSON
- File Handling
- Date Handling
- Lists and Dictionaries
